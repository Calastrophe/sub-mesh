Install a mesh client

Download both programs for your platform. mesh-daemon connects this machine to the mesh; meshctl manages the daemon.

Linux daemon x86_64 Linux meshctl x86_64 Windows daemon x86_64 Windows meshctl x86_64

Use the same origin you use to open the dashboard. Include a port if needed; do not add a path.

For HTTP over Tailscale only. Leave blank to trust the server under this machine's Tailscale login. HTTPS uses its TLS certificate instead.

Save the downloaded file as daemon.toml in your mesh config directory:

  • Linux: ~/.config/mesh/daemon.toml (or under $XDG_CONFIG_HOME)
  • Windows: %APPDATA%\mesh\daemon.toml

After saving the config, start mesh-daemon. Run meshctl login codex or meshctl login claude to add an account.
